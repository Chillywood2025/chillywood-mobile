# Tax Readiness Checklist

Status: draft tax-readiness checklist. Not tax advice. Consult a qualified tax professional before production payouts, production merch, or production creator monetization. Production money, payouts, cash-out, withdrawal, transfer, and payable balances are not active.

Required review:

- define platform vs creator tax responsibility;
- define platform pricing/fee control and how net receipts are calculated;
- confirm Stripe Connect 1099 strategy based on the selected Connect model;
- collect creator tax identity through Stripe Connect where possible;
- define W-9 / W-8 strategy;
- define US and non-US creator eligibility;
- define annual threshold monitoring;
- define tax form delivery and support workflow;
- define record retention and deletion exceptions;
- define creator statements/downloads for future dashboard;
- review merch sales tax, VAT, GST, and nexus;
- review digital tax/compliance for paid access if applicable;
- review purchase/refund/chargeback records needed for tax;
- update Data Safety/privacy docs before identity, tax, shipping, or financial data collection changes.

Reference links:

- IRS gig economy tax center: https://www.irs.gov/businesses/gig-economy-tax-center
- Stripe Connect tax reporting: https://docs.stripe.com/connect/get-started-tax-reporting
- Stripe physical-goods tax docs: https://docs.stripe.com/tax/physical-goods
