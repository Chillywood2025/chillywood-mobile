# Product Experience Constitution

Status: machine-readable constitution added; Owner baseline approval not yet
recorded.

Source:

`config/intelligence/product-experience-constitution.json`

The constitution is intentionally marked:

- `status`: `needs_product_baseline_review`
- `ownerApprovalVersion`: `not_approved_yet`

This prevents the system from treating the current app as an approved visual
baseline. Before redesign authority exists, the visual sentinel may create
evidence-based outlier findings and baseline-review requests only.

The constitution includes:

- mobile-first principles;
- streaming-content density expectations;
- route completion expectations;
- loading-state deadlines;
- empty/error/offline expectations;
- card viewport and aspect-ratio metrics;
- typography and Dynamic Type constraints;
- phone/tablet breakpoints;
- screenshot provenance requirements;
- explicit no-production-mutation authority.
