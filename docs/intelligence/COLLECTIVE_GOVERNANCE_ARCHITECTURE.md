# Collective Intelligence and Governance Architecture

Status: `collective_governance_in_progress`

Source base: `747a6d1257c029001e0f8051bf385b6bf1b5c261`

This branch builds the bounded governance layer above the hardened cognitive
scaffold. It does not reopen or modify the frozen hardening branch.

The governance layer will provide:

- evidence-bound advisory council deliberation;
- blind first assessments and explicit alternatives;
- risk-based quorum, mandatory veto, and preserved dissent;
- immutable decision manifests;
- owner-controlled 24-hour approval versions;
- exact capability, budget, lease, receipt, and evaluator binding;
- bounded Level 0/1 canary controls.

It grants no authority to merge, release, deploy application changes, move
money, alter user rights, weaken authentication or RLS, change roles, enforce
moderation, mutate provider products, or approve itself.

All cognitive/governance migrations, functions, credentials, and schedules
remain undeployed until the exact-head predeployment review gates pass.
