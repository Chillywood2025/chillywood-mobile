# Cognitive Level 0/1 Operating Model

Level 0 is public/non-personal research, repository analysis, architecture/UX
mapping, and owner digests. Level 1 adds advisory collective deliberation and
owner-approved draft-PR-only engineering through the hardened executor.

Every task is bounded by evidence freshness, budget, deadline, dedupe, no-work exit,
kill switch, decision manifest, approval envelope, short-lived capability,
resource lease, postflight receipt, rollback, and independent evaluation.

Level 0/1 cannot merge, deploy product changes, publish OTA, release to stores, move
money, change rights/auth/RLS/roles/moderation/ranking/provider products, or
self-approve. Level 2 production repair stays off. Level 3/4 remains exact
owner-gated permanently.
