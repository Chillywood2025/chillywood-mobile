# Owner Cognitive Control Center

Status: `SOURCE_COMPLETE_NOT_DEPLOYED`

The Admin Command Center includes an owner-only, read-only foundation view. It shows the system state, task/research/plan/experiment/budget/evaluation categories, blockers, rollback readiness, and approval boundaries from committed source contracts.

Pause, stop, deny, approve exact scope, reduce budget, quarantine playbook, and emergency stop are visible only as disabled foundation placeholders. No production execution RPC or control is wired. The surface does not grant new roles and does not bypass the existing approval system.
