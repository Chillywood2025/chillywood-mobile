# Chi'lly Chat Sound Licenses

Date: 2026-06-10

This file records the source and license proof for every bundled Chi'lly Chat notification/ringtone sound committed under `assets/sounds/chilly-chat/`.

The same files are mirrored under `android/app/src/main/res/raw/` with Android-safe filenames so checked-in native Android builds include the notification sound resources. The Android raw copies carry the same source and license as the app asset copies.

Source pack used for all sounds:

- Official source URL: https://www.kenney.nl/assets/ui-audio
- Repository mirror used for source WAV files: https://github.com/Calinou/kenney-ui-audio
- Source title: UI Audio
- Author/creator: Kenney Vleugels / Kenney
- License type: Creative Commons Zero, CC0 1.0 Universal
- License URL: https://creativecommons.org/publicdomain/zero/1.0/
- Commercial app use allowed: yes
- Redistribution inside app bundle allowed: yes
- Attribution required: no
- Download date: 2026-06-10

The local source pack license states that these assets may be used in personal and commercial projects and that credit is not mandatory. Kenney's official UI Audio page lists the license as Creative Commons CC0. The GitHub mirror used for source WAV access also identifies the pack as CC0 1.0 Universal.

## Native Build Boundary

These files are bundled through the Expo notifications config plugin. Background push notification channel sounds require a new native/internal Android build. OTA updates alone cannot add native notification sound resources to an already installed runtime.

User downloaded/imported sounds remain in-app-only for V1 and are not promised for Android background push notification sounds.
