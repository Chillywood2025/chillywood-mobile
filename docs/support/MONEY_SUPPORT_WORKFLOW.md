# Money Support Workflow

Status: draft support workflow. Production money, payouts, cash-out, withdrawal, transfer, and payable balances are not active.

## Queues

- Premium purchase issue
- Paid content access issue
- Watch-Party ticket/access/seat issue
- Event pass issue
- Tip/support issue
- Merch order issue
- Refund request
- Chargeback/dispute
- Creator payout status
- KYC/tax onboarding help
- Fraud/risk hold appeal
- Account/payment safety issue

## Standard Category Fields

Support must collect: user account, product type, provider/order/intent id where safe, source id, screenshot if useful, timeline, current access state, refund/dispute status, and support history.

## Support Can

- explain current sandbox/production status;
- check safe readouts;
- escalate to Owner/Admin, provider, legal, tax, risk, or fulfillment owner;
- document evidence and audit reason;
- provide non-legal/non-tax process guidance.

## Support Cannot Promise

- guaranteed payout;
- guaranteed refund;
- guaranteed access if content/room/event is unsafe or unavailable;
- guaranteed merch delivery without fulfillment proof;
- tax or legal advice;
- production activation timing.
