# Merch Support Playbook

Status: draft support playbook. Production merch is not active.

## User-Facing Template

Thanks for contacting Chi'llwood merch support. We can review the order status, fulfillment state, shipping/tracking information if available, and any damaged/missing item evidence.

## Support Steps

- collect order id, product/SKU, shipping contact, issue type, and photos if damaged/wrong item;
- inspect merch order, order item, fulfillment status, Stripe event, and support history;
- check inventory/fulfillment owner;
- decide refund, replacement, cancellation, or escalation;
- record audit reason.

Support cannot promise delivery timing beyond the approved shipping policy or guarantee refund/exchange outside the approved return policy.
